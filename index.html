Mojo
prefix.dev

A pure Mojo machine learning library built with Scikit-Learn ergonomics and 0 Python interop overhead. Implements Linear/Logistic Regression, Random Forests, and K-Means.

  • Leverages compile-time traits, static polymorphism, and generic SIMD types across float/int bit-widths to optimize execution performance.
  • Integrates LAPACK and BLAS for dense linear algebra computation.
  • Accepted as one of the first 50 packages in Modular's official index on prefix.dev.
